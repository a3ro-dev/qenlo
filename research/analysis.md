# Evidence synthesis

The revised paper accounts for 563,644 retained timed observations after excluding one incomplete 2,506-sample CPU development run and duplicate cloud mirrors. Of these, 558,644 satisfy their stated recall gate; the remaining 5,000 are the retained cuVS recall failure. Counts are recomputed in `data/processed/evidence_inventory.csv`.

The evidence supports a boundary, not dominance.

The user-supplied Android device-lab records extend the native evidence to Android 16 on a Mediatek MT6897 and Mali-G615 MC6/Vulkan. CPU wins the 10k×384 quick dense cell at P95 (5.767 vs 12.487 ms), whereas WGPU wins at 100k×384 in both the 64-sample full run (16.975 vs 29.436 ms) and 512-sample soak (17.678 vs 27.019 ms). The soak ratio is 1.53× CPU/WGPU. This is a qualitative reversal, not a controlled crossover bracket, because suite size and corpus size change together. Soak IVF-Flat (21.453 ms) and IVF-SQ8 (37.090 ms) do not beat exact WGPU (17.678 ms) despite recall 1.0. The batch-8 and automatic-routing cells lack matched fixed-policy counterfactuals and are not normalized per query.

On a post-hoc native RTX 4050 sweep at 100k×384, CPU and compact-row WGPU search reverse between E=2,000 and E=3,000: P95 is 0.5198 versus 0.6340 ms at E=2,000 and 0.9563 versus 0.8144 ms at E=3,000. WGPU remains faster at 4k, 6k, 8k, and 10k. Every cell has recall@10=1.0. The sweep localizes the observed batch-1 boundary but, because it was designed after endpoint inspection, is descriptive rather than confirmatory. Code-path inspection shows that each timed compact-row call traverses the predicate once to count eligible rows and again to build a fresh row-ID list, then uploads that list and the query. Vectors and scratch allocations remain resident. The bracket therefore characterizes this implementation, including its duplicated filter pass; it is not an optimized cached-list frontier.

On the held-out synthetic A6000 matrix, FAISS Flat has lower P95 at E=1,000 (0.086 vs 0.098 ms) and E=10,000 (0.137 vs 0.156 ms). The buffered research CUDA exhaustive prototype has lower P95 at E=100,000 (0.567 vs 0.789 ms, 1.39×) and E=1,000,000 (4.668 vs 6.347 ms, 1.36×). Thus the implementation crossover lies between 10k and 100k eligible rows for this GPU, dimension, batch, and API boundary. This does not establish a shipped-Qenlo WGPU crossover.

The independently-oracled real TopK cell at E=10,026 reports P95 0.197 ms for NumPy exact and 0.132 ms for FAISS GPU Flat, both recall@10=1.0. The retained Qenlo CUDA prototype was 0.171 ms end-to-end and therefore slower than FAISS. Its 0.1196 ms kernel-only observation is not comparable.

The retained real 100k×384 Rust cohort shows the expected CPU/GPU reversal: all rows eligible gives Qenlo WGPU predicate P95 3.240 ms versus CPU 16.657 ms (5.14×, bootstrap interval [3.55,6.77]), whereas 1% eligibility gives GPU 2.883 ms versus CPU 0.230 ms. At 1% eligibility, compact-row WGPU is 4.26× faster than predicate evaluation; at all-row eligibility, predicate evaluation is 1.31× faster than compact rows. This supports H3 and shows that predicate representation is a routing variable. H2 remains open because equal eligible counts across total corpus sizes were not measured on one host.

At 100k×384 with all rows eligible, the controlled Windows cohort compares identical data, query ranges, process boundary, and hardware. Expansion 128 was selected on 1,000 tuning queries (recall 0.9932); held-out USearch reached recall 0.99224 and P95 3.625 ms. Exact WGPU reached recall 0.99998 and P95 3.240 ms. Its nominal 1.12× advantage has a whole-run bootstrap interval [0.77,1.54], so the experiment does not establish a reliable latency winner. It does show that exact GPU is competitive with HNSW above 0.99 recall in this cell. Batching and router behavior have smaller device-lab evidence; correlation remains open.

H1 is partially supported: exhaustive GPU beats CPU in a dense real Rust workload, is latency-competitive with one tuned USearch point at recall above 0.99, and a transparent CUDA exhaustive implementation beats FAISS Flat at large E. Chroma's separate Windows cell is faster (1.130 ms P95 at recall 0.99414), so no system-independent ANN victory is claimed. The USearch interval crosses parity. H4 has supporting device-lab evidence only; H5 has one controlled point rather than a curve; H6 remains inconclusive beyond correctness of the current threshold decisions.
